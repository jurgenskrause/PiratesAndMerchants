# Port economic dashboard

Click a port office, dock or town quarter to open the port authority dashboard. Ship clicks keep their existing inspector. Dragging and pinching the map do not open the dashboard. The port register also has an Open port information button for keyboard access.

The economic view reads the active worker's accounts, ownership records, funded book and transfer history. It displays population/capacity, prosperity when recorded, docks/queue, port balance, spendable and committed funds, separately owned manufacturing capital, every cargo's physical market stock and listed quantity, usable town buffer, actual best asks/bids with executable depth, paid inbound quantities, individual industry accounts/recipes/internal inputs, primary producers, protected handling and actual recent fills. Detailed stores/reservations and financial receipts are expandable. Faction funds and ship purses are not presented as spendable port capital.

Charts for all cargo opens a responsive grid of port-scoped timelines. Explore enlarges one cargo and lists its recent movements. Hover or tap trade markers for ship, origin/destination, accepted price, quantity and payment recipients. Timeline range controls apply to every chart. Lines are labeled as stock-based reference prices, not executable market quotes. Current bids/asks and actual accepted prices remain separate. All monetary labels use the shared two-decimal formatter.

Inspection is read-only and returns detached snapshots. Port history is filtered before copying other ports' series, and uses existing bounded/compacted history. The view refreshes every 1.5 seconds while open, including while simulation is paused. Requests are session-scoped; stale port/view/session replies are ignored. Live chart updates retain canvases and controls. Closing cancels polling. Restart/regeneration clears old data. Before simulation, the screen explicitly shows initial-world values; it does not invent a price history.

Verified with focused dashboard DOM/canvas tests, account/goods/book inspection parity, port-only history, worker protocol, stopped-worker requests, stale replies, preview/keyboard/close behavior, existing history/overview, worker configuration, bootstrap, port visibility, conservation and generated-world merchant traffic suites. Browser visual verification was unavailable; no interactive browser QA was performed.
