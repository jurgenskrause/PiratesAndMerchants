## Prompt template

Use case: stylized-concept. Asset type: transparent top-down sailing game sprite atlas. Use the attached sloop ONLY as a style reference: warm brown wooden hull, inked outlines, ivory canvas, detailed painted game art. Create a NEW {SHIP}. Exactly FIVE equal-width columns in ONE horizontal strip, no labels or text, all bows pointing straight UP, strict orthographic TOP DOWN view, centered hull in each cell. The SAME hull, masts, orientation, scale and center in every column. Leave generous transparent gaps and margins; every sail must fit its own column. Five states left to right: 0 bare poles with all canvas tightly furled; 1 shortened storm canvas 25%; 2 easy sail 50%; 3 working sail 75%; 4 full sail 100%. No flags or pennants, no water, no wake, no shadows outside hull, no perspective tilt. All hull tips at same top and bottom height. Landscape atlas. Ship details: {DETAIL}.

## Subjects

Schooner: two masts and fore-and-aft rig, narrow fast hull.
Brigantine: square foremast, gaff mainmast, medium hull.
Fluyt: three masts, broad pear-shaped cargo hull, ochre trim.
Frigate: three masts, square rig, long streamlined hull, navy trim.
War Galleon: three masts, raised castles, heavy red-and-gold hull.
Man-of-War: three masts, square rig, massive black-and-yellow capital hull.

The existing sloop atlas was the style reference for all six. Assets are rendered with separately calibrated frame anchors.
